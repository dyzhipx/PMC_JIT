2. Fitur A: Tombol Koreksi Cepat Transit (Poka-Yoke Bypass)

2.1 Latar Belakang Masalah

Masalah: Jika Helper produksi mengambil material dari area Transit tanpa scan barcode, maka:
  • Stok di sistem Transit masih tercatat penuh (padahal fisiknya sudah kosong)
  • Gudang tidak bisa mengirim barang baru (terblokir oleh aturan Stock Over)
  • Alur produksi terhenti sampai ada yang menyadari kesalahan

2.2 Solusi

Tombol "🔧 Koreksi Cepat" di halaman Info Distribusi Transit, hanya bisa diakses oleh Admin Transit, untuk mengoreksi jumlah pallet ke angka fisik aktual. Setiap koreksi akan tercatat permanen sebagai bahan evaluasi.

2.3 Alur Kerja Operator

1. Gudang mencoba kirim barang → Layar muncul "⚠️ STOCK OVER" 2. Gudang menelepon Admin Transit → "Kenapa di sistem penuh?" 3. Admin Transit cek fisik blok → "Oh ternyata kosong, helper ambil tanpa scan" 4. Admin Transit klik "🔧 Koreksi" di layar Info Distribusi 5. Input: Stok Fisik = 2 (dari 4), Alasan = "Helper Lupa Scan" 6. Sistem langsung memotong 2 pallet dari database 7. Gudang bisa kirim lagi ✅ 8. Log koreksi tersimpan permanen → bahan evaluasi HRD

3. Fitur B: Sistem Rekonsiliasi Material Otomatis

3.1 Latar Belakang Masalah

Masalah: Saat ini tidak ada cara untuk mengetahui berapa material yang seharusnya dipakai vs berapa yang tercatat keluar dari transit. Jika helper lupa scan 1 pallet, tidak ada yang tahu sampai opname bulanan.

3.2 Solusi

Sistem kalkulasi otomatis yang menyilangkan data Output Produksi (Counter Box) × BOM (rumus material) vs Scan OUT Transit + Reject Material untuk mendeteksi selisih secara real-time per shift.

3.3 Rumus Inti

Konsumsi Teoritis (Pallet) = (Output Box × Koefisien BOM) ÷ Qty per Pallet Selisih = Konsumsi Teoritis − Scan OUT Transit − Reject (dalam Pallet) Jika Selisih > 0 → ⚠️ ANOMALI (ada pallet yang ditarik tanpa scan) Jika Selisih = 0 → ✅ OK (semua tercatat dengan benar) Jika Selisih < 0 → 🔵 SURPLUS (scan lebih dari kebutuhan, mungkin buffer)

3.4 Contoh Perhitungan Nyata

Skenario: Line A, Shift 2 — Memproduksi SKU "ABC Mocca 250g"

3.5 Alur Kerja Operator (Akhir Shift)

1. Kepala Regu buka menu "🔍 Rekonsiliasi Material" 2. Tab "Input Output Produksi": → Pilih Shift 2, Line A, SKU "ABC Mocca 250g" → Ketik: 4.000 box (dibaca dari display counter mesin) → Klik Simpan 3. Tab "Input Reject Material" (jika ada): → Input material yang rusak/cacat hari ini beserta alasannya 4. Tab "Laporan Anomali": → Sistem langsung menampilkan tabel selisih per material → Jika ada baris MERAH → ada kelalaian scan yang terdeteksi
